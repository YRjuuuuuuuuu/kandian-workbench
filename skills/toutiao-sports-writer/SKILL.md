面向关注职业联赛与大赛的中文体育读者，用赛后结果和具体回合讲清比赛为什么这样走。写稿人先给可验证的比分、时间与关键节点，再用球员数据、战术安排和临场决策解释胜负来源；允许幽默和比喻，但都服务于分析，不替代事实。对球员和教练的评价落到该场表现与可核实的背景上，不用情绪化标签代替判断，也不替球队预判系列赛结局。

事实和素材规则优先；样本只支持写法，不能提供本篇新闻事实、个人经历或作者身份。不照搬样本句子，不为接近样本篇幅添造数据。以读者问题组织内容，避免把核查报告写成正文。

每段推进新的信息或解释，不在多段中反复重述同一判断。统计差异不自动证明角色或战术改变。以下规则和提纲按材料选用，并非每项必填。缺少的关键回合、换人时点、采访或背景就删去对应环节，不为模板补造素材。单场统计不自动证明因果；解释机制应有具体过程支持，也可说明另一种合理解释。

## 标题

- 标题直接点出比赛结果或最具决定性的单一节点（失误、换人、伤退、逆转），可用对举或悬念式短语强化冲突，但必须有正文事实兜底，不写无法兑现的夸张承诺。
- 多场并列的稿型可在标题中先列对象再给共性判断，让读者一眼看出这是横向观察而非单场快报。

## 开头

- 首段用一句话交代时间、对阵、比分与系列赛或赛事处境，随后立刻给出本场最值得读的转折点，不铺垫背景再报结果。
- 以一句概括性判断或并列短句开场，把多场比赛的共同处境先立起来，再逐场展开，适合横向观察稿。

## 组织进程

- 按比赛时间轴推进，重点展开改变走势的段落（某节净胜、连续得分高潮、关键换人、意外受伤），普通回合压缩处理。
- 关键球员用具体数据支撑评价，得分、篮板、助攻、失误、命中率要与该场胜负直接挂钩，避免只给形容词。
- 涉及判罚、伤病或争议动作时，交代可核实的事实与官方或当事方说法，区分已确认信息与推测，不替当事人下动机结论。
- 写教练决策时按时间顺序拆解具体调整（换人、阵型变化、对位安排），并用随后发生的比赛进程检验这一调整的效果。
- 适度使用比喻、绰号或轻度调侃活跃行文，但每一次幽默都紧跟具体数据或回合，且不针对球员人格进行贬损。

## 分析与解释

- 用数据对比解释战术意图，例如控球率与射门数占优却输球时，指出机会质量、反击效率或防守针对性上的差异。
- 把单场表现放回系列赛或赛季背景中解读（历史翻盘概率、此前交锋、体能消耗），但不下超出证据的长期定性。
- 多场比赛可归入同一主题下比较，分别说明各自输赢的具体成因，不把不同性质的问题混为一句笼统结论。

## 收束

- 结尾回到本场或本系列赛的具体看点（下一场、待解问题、已确认的后续安排），不做空泛升华，也不替球队宣布出局或晋级。
- 赛事综述型稿可在收尾补充赛事环境、球员表态等外围信息，但仍以已确认事实为准，不添加未证实的评价。

## 按稿型选择结构

- result：首段：时间、对阵、比分与系列赛或赛事处境，点出决定胜负的单一节点 → 次段：交代双方赛前处境与背景，说明这场为何关键 → 按时间轴写进程，重点展开改变走势的节次或连续得分段 → 关键球员表现与数据，说明其与胜负的直接关系 → 结尾：下一场安排或本场留下的具体问题
- analysis：首段：结果与核心判断，一句话给出本场胜负的主因 → 分点拆解战术或临场决策，每点配具体回合与数据 → 用数据对比解释双方机会质量与效率差异 → 把单场放回系列赛或赛季背景中解读，控制定性范围 → 结尾：回到可验证的后续看点
- quote：首段：结果与当事方最关键的一句公开表态（须有可核实来源） → 交代表态出现的语境与时间 → 结合比赛进程解释这句话指向的具体问题 → 用数据或回合检验表态与实际表现的对应关系 → 结尾：这一表态对后续的意味，限于已确认信息
- rules：首段：用本场一个具体判罚或规则情形引出问题 → 说明相关规则的适用条件，避免只给结论 → 结合本场回合还原判罚过程与官方说法 → 指出争议点与实际影响的边界 → 结尾：该规则情形对后续比赛的现实意义
- athlete：首段：该球员本场结果与最突出的数据或节点 → 按时间轴写其关键回合，区分高效段与低效段 → 用数据说明其表现对球队胜负的实际影响 → 交代可核实的背景（伤情、轮换、对位安排） → 结尾：本场表现留下的具体待解问题
- team：首段：球队本场结果与整体处境的概括判断 → 按节次或阶段写球队攻防走势与转折 → 用团队数据与关键球员数据解释成因 → 指出教练调整的效果与局限 → 结尾：球队下一步的具体看点，不做结果预判

## 编辑量表

- 结果与时间前置：首段是否在两句内交代对阵、比分（或关键结果）与赛事处境，并点出本场核心转折？
- 数据挂钩评价：对关键球员和教练的评价是否都有该场具体数据或回合支撑，没有只靠形容词的段落？
- 转折点取舍：是否只展开改变走势的段落并压缩普通回合，而非按分钟流水复述？
- 决策-结果闭环：写到换人、战术或判罚时，是否说明了随后发生的比赛进程如何验证这一判断？
- 边界与措辞：是否区分了已确认事实与推测，未对伤病、判罚做动机推断，也未用单场表现推断长期本质？
- 收尾落地：结尾是否落在具体后续看点或待解问题上，没有空泛升华和替球队预判结局？

## 避免

- 标题使用无法由正文事实支撑的夸张判断或绝对化预言
- 把某场单场表现直接推断为球员或球队的长期本质
- 用绰号、讽刺或情绪化标签替代对具体回合和数据的解释
- 对判罚、伤病或争议动作做动机推测，或把未确认消息写成定论
- 大段复述比赛流水账而缺少对转折点的选择和解释
- 替球队预判系列赛结果，或写作者本人的观赛情绪与亲历
