# 看点工场 Windows 独立版

1. 将 ZIP 完整解压到有写权限的目录。双击其中的 **看点工场.exe**，控制台会启动工作台并打开浏览器。
2. 在工作台打开「AI 模型」，录入自己的 DeepSeek API Key 并测试连接。找题、核查、写作、润色、改稿、配图核对及风格学习均使用 DeepSeek API。联网工具需要联网和可用额度。
3. 在首页交给 Agent 找题，审核候选后开始生产。在稿件中心编辑、预览并导出 Word。上传和发布在目标平台后台由你完成。
4. 等稿件显示「已保存」后，在控制台点击「停止工作台」，也可以双击「停止工作台.cmd」。关闭网页后，后台服务和定时任务仍可运行。

发行包适用于 Windows 10/11 x64，内置 Python、Playwright 和无头 Chromium。公开热榜可能因连接、登录要求或页面调整暂不可读，此时 Agent 会继续查询公开赛事来源。实时发布前请核对事实、图片授权与目标平台的 AI 标注规则。

每个解压目录使用自己的 `data/`。迁移时先停止旧工作台，备份旧 `data/`，再复制到新位置。DeepSeek Key 使用当前 Windows 用户的 DPAPI 保存，换机器或用户后通常需要重新填写。尽量保留完整目录，桌面可以放 EXE 的快捷方式。

在 PowerShell 中可用 `Get-FileHash -Algorithm SHA256 -LiteralPath '压缩包文件名.zip'` 核对发布页提供的 SHA-256。启动器未签名。
